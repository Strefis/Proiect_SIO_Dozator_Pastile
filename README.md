# Proiect_SIO_Dozator_Pastile
Dozator inteligent de pastile cu autentificare prin amprentă

Membri: Dușa Adriana Cristina, Carcalețeanu Cristian Nicolae, Andronache Darius Fabian

Proiectul are ca scop automatizarea procesului de dozare a medicamentelor prin utilizarea unui sistem pe baza de Arduino.

Perifericele sistemului:

-senzor amprenta AS608

-servomotor SG90

-stepper 28BYJ-48

-RTC DS3231

- display LED 16x2

- senzor optic 

Pastilele se vor introduce intr-o roata, sub care exista un disc cu o fanta. La ora programata, servo-ul actioneaza compartimentele de pastile si se aliniaza cu fanta, astfel incat sa cada pastila intr-o cutie, care este acoperita cu un capac de un servo. Aceasta cutie poate fi deschisa numai cu amprenta. Daca amprenta este buna, se ofera acces catre pastila.
